# Moje HTML stránka

Jednoduchá statická stránka vytvořená pro rychlé nasazení a úpravy.

Jak spustit

1. Otevřete soubor `index.html` ve vašem prohlížeči (dvakrát klikněte nebo použijte "Otevřít v..." v editoru).
2. Upravit obsah editací `index.html` a styl v `style.css`.

Co můžete změnit

- Nadpisy a texty v `index.html`.
- Barvy a rozložení v `style.css`.

Pokud chcete, můžu přidat další sekce, šablonu pro blog nebo nasazení na GitHub Pages.
